# Project 1: Personal Info Card

## Objective
Create a program that displays a nicely formatted "business card" with your personal information.

## Requirements
Your program should:

1. **Variables**: Create variables for:
   - Your full name
   - Your age
   - Your favorite programming language (start with "Python"!)
   - Your email
   - A fun fact about yourself

2. **Display**: Print a formatted card that looks like this:
   ```
   ================================
           PERSONAL INFO CARD
   ================================
   Name: [Your Name]
   Age: [Your Age]
   Favorite Language: Python
   Email: [Your Email]
   Fun Fact: [Your Fun Fact]
   ================================
   ```

3. **Code Quality**:
   - Use descriptive variable names
   - Add a docstring at the top explaining what the program does
   - Include comments explaining each section
   - Follow the template structure provided

## Bonus Challenges
- Calculate and display how many days old you are (age * 365)
- Add your favorite quote
- Make the card even prettier with ASCII art

## Learning Goals
- Practice creating and using variables
- Understand different data types (string, integer)
- Learn basic string formatting and output
- Follow Python coding best practices
