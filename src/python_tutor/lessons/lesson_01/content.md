# Variables and Data Types

## What are Variables?
Variables are containers for storing data values. In Python, you don't need to declare variables explicitly - just assign a value!

## Basic Data Types
- **String (str)**: Text data, enclosed in quotes
- **Integer (int)**: Whole numbers
- **Float (float)**: Decimal numbers
- **Boolean (bool)**: True or False values

## Creating Variables
```python
# String variable
name = "Alice"

# Integer variable
age = 25

# Float variable
height = 5.6

# Boolean variable
is_student = True
```

## Variable Naming Rules
- Start with letter or underscore
- Can contain letters, numbers, underscores
- Case-sensitive
- Use descriptive names
