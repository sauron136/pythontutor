# Variables and Data Types

## What are Variables?

Variables are like containers that store information for your programs. Think of them like labeled boxes where you can put different kinds of stuff!

🧬 **Science Analogy**: Variables are like the different compartments in a cell - the nucleus stores DNA (strings), mitochondria store energy (numbers), and each has a specific job and contains specific types of information!

## Basic Data Types

Python has several built-in data types:

- **String (str)**: Text data, like names or messages
- **Integer (int)**: Whole numbers, like age or count  
- **Float (float)**: Decimal numbers, like height or price
- **Boolean (bool)**: True or False values, like yes/no questions

## Creating Variables

Let's start by creating some variables! Remember, in Python you don't need to declare the type - Python figures it out automatically.

```python
# String variable - notice the quotes!
name = "Alice"
```

```python
# Integer variable - no quotes for numbers
age = 25
```

```python
# Float variable - has a decimal point
height = 5.6
```

```python
# Boolean variable - True or False (capital letters!)
is_student = True
```

## Printing Variables

Once you create variables, you can display their values using the print() function:

```python
print(name)
```

```python
print("I am", age, "years old")
```

```python
print(f"My height is {height} feet")
```

## Variable Naming Rules

🧪 **Chemistry Analogy**: Just like chemical elements have specific naming rules (Carbon = C, Hydrogen = H), Python variables have rules too!

**Rules you MUST follow:**
- Start with a letter (a-z, A-Z) or underscore (_)
- Can contain letters, numbers, and underscores
- Case-sensitive (Name ≠ name ≠ NAME)
- Cannot use Python keywords (like `print`, `if`, `for`)

**Best Practices:**
- Use descriptive names: `user_age` instead of `a`
- Use snake_case: `first_name` instead of `firstName`
- Keep it readable: `temperature_celsius` tells you more than `temp`

```python
# Good variable names
user_name = "Bob"
total_score = 95
is_game_over = False
```
