# Implementation Guide: Personal Info Card

## 🎯 What You Need to Complete

You need to complete the `main()` function in `main.py` by implementing 3 main parts:

### Step 1: Create Variables (5 minutes)
Replace the TODO comments with actual variables:
```python
full_name = "Alice Johnson"        # Your actual name
age = 20                          # Your actual age  
favorite_language = "Python"     # Programming language
email = "alice@example.com"       # Your email
fun_fact = "I love hiking!"       # Something interesting
```

### Step 2: Display the Card (10 minutes)
Use f-string formatting or .format() to insert your variables:
```python
print(f"Name: {full_name}")
print(f"Age: {age}")
print(f"Favorite Language: {favorite_language}")
print(f"Email: {email}")
print(f"Fun Fact: {fun_fact}")
```

### Step 3: Add Bonus Features (5 minutes)
Calculate and display extra information:
```python
days_alive = age * 365
print(f"\nBonus: You've been alive for {days_alive} days!")
```

## 🧪 Test Your Code
1. Save your changes
2. Run: `python3 main.py`
3. You should see a nicely formatted card with your info

## 💡 Success Criteria
- ✅ Creates at least 5 variables
- ✅ Displays formatted card
- ✅ Uses proper variable names
- ✅ Code runs without errors
